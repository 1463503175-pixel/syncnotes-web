# 陈笃山记事本 Windows EXE 使用说明

版本：1.1.7  
适用系统：Windows 10 / Windows 11

## 1. 下载后怎么使用

从 GitHub Release 下载：

```text
Chen Dushan Notes 1.1.7.exe
```

双击运行即可。首次打开时，程序会进入“首次设置”页面。

## 2. 首次设置

首次设置需要填写三项：

| 项目 | 说明 |
| --- | --- |
| 账号 | 自己创建的本地账号 |
| 密码 | 自己创建的本地密码 |
| 保存路径 | 笔记数据、附件、AI 配置保存的位置 |

保存路径可以选择任意你有权限写入的文件夹，例如：

```text
D:\我的记事本数据
E:\SyncNotesData
```

创建完成后，程序会自动进入记事本。

## 3. 保存路径里会生成什么

选择保存路径后，程序会自动创建这些文件夹和文件：

```text
你选择的保存路径
├─ data
│  ├─ access.json              本地账号密码
│  ├─ notes.json               笔记数据
│  ├─ drafts.json              草稿数据
│  ├─ sync-meta.json           同步状态
│  └─ desktop-ai-config.json   AI API Key 和模型配置
└─ attachments                 图片、录音、视频、文档等附件
```

以后再次打开 EXE，会自动读取这个保存路径，不需要重新设置。

## 4. 登录和账号

这个 EXE 是本地记事本程序。别人下载后可以创建自己的本地账号和密码，不需要使用作者的账号。

账号密码保存在你选择的保存路径中，只用于本机访问记事本。

## 5. AI 设置在哪里

进入记事本后，点击左侧菜单的“设置”。

在“记事本设置”窗口里，除了记事本名称、主题色，还会看到“AI 设置”区域。

可以填写：

| 项目 | 示例 |
| --- | --- |
| API 地址 | `https://api.openai.com/v1` |
| API Key | `sk-...` |
| 文本模型 | `gpt-4o-mini` |
| 图片模型 | `gpt-4o` |
| 音频模型 | `whisper-1` |

图片模型和音频模型可以留空；留空时默认使用文本模型。

## 6. 图标说明

1.1.7 使用 `E:\THING\像.jpg` 生成应用图标、托盘图标和 EXE 文件图标。

## 7. 数据迁移

如果换电脑使用，只需要把你选择的保存路径整个复制到新电脑，然后首次设置时选择同一个数据文件夹，或者把数据放到你想要的新路径中。

建议定期备份整个保存路径，尤其是：

```text
data
attachments
```

## 8. 常见问题

### 打开后看不到最新界面

请先退出旧版程序，包括右下角托盘里的 `Chen Dushan Notes`，再打开新版 EXE。

### 正文无法输入

请确认打开的是最新版 `Chen Dushan Notes 1.1.7.exe`，并退出旧版托盘程序后重新打开。

### 托盘图标透明

1.1.7 已改为使用真实 `icon.ico`，不再使用动态 SVG 托盘图标。请退出旧版托盘程序后打开 1.1.7。

### AI 功能不可用

请检查：

1. API 地址是否正确。
2. API Key 是否有效。
3. 文本模型、图片模型、音频模型是否填写为当前 API 支持的模型。
4. 电脑是否能正常访问对应 API 服务。
